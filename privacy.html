Política de privacidad

Actualizada el 31 de octubre de 2026.

Esta política describe el programa local ArchBook y esta web informativa. El proyecto es mantenido por Fernando (ElFer10) para uso personal.

Datos consultados y finalidad

  • Gmail: consulta el contador de mensajes no leídos de la etiqueta Recibidos para mostrarlo en Waybar. Solicita gmail.metadata, que permite acceso a metadatos; el programa no descarga cuerpos, adjuntos ni cabeceras de mensajes.
  • Calendar: utiliza calendar.readonly para consultar la lista de calendarios y sus eventos. Muestra títulos, fechas, horas, nombres de calendarios y enlaces de los eventos. Las respuestas de la API pueden incluir otros campos del evento, pero el programa no los incorpora a su caché.
  • Tasks: utiliza tasks.readonly para consultar listas y tareas pendientes. Muestra títulos, fechas, nombres de listas y enlaces. Las respuestas pueden incluir notas u otros campos, que no se incorporan a la caché.

Estos permisos se usan exclusivamente para el contador y la agenda. El programa no envía correos ni modifica datos de Google.

Autorización y almacenamiento

El inicio de sesión se realiza en Google mediante OAuth. ArchBook no solicita ni almacena la contraseña de Google. Guarda las credenciales OAuth y los tokens en ~/.config/archbook-google/, y una caché del contador y de la agenda en ~/.cache/archbook-google/. Los archivos se protegen con permisos del sistema para el usuario; el programa no añade cifrado propio.

Los datos de cada servicio se reemplazan tras una consulta correcta. Si una consulta falla, pueden conservarse los últimos datos con un aviso de error. Los archivos permanecen en el equipo hasta que se sustituyen o el usuario los elimina. Las copias de seguridad del equipo, si existen, pueden conservar copias según su configuración.

Transferencias y uso de datos

El programa se comunica con Google para autorizar y consultar sus APIs. Cuando el usuario abre un elemento, el navegador accede al sitio de Google correspondiente. ArchBook no incorpora un servidor intermediario, telemetría, publicidad ni funciones de venta de datos. No utiliza datos de Google para entrenar modelos de inteligencia artificial.

El uso y la transferencia de información recibida de las APIs de Google se ajustan a la Política de Datos de Usuario de los Servicios API de Google, incluidos los requisitos de Uso Limitado.

Revocar el acceso y eliminar los datos locales

El usuario puede revocar el acceso de ArchBook desde las conexiones de su cuenta de Google. Puede eliminar las carpetas de credenciales y caché indicadas arriba, y retirar el módulo de Waybar para detener las consultas. Revocar el acceso no elimina por sí solo la caché local; eliminar la caché no revoca los permisos de Google. Ninguna de estas acciones elimina los correos, eventos o tareas originales de la cuenta.

Esta web

La web es estática y no contiene formularios, cookies propias ni herramientas de analítica. Se aloja en GitHub Pages; GitHub puede tratar información técnica de las visitas conforme a su declaración de privacidad. La web no recibe los datos de Google consultados por el programa local.

Contacto y cambios

Las consultas pueden dirigirse a las incidencias del repositorio. Son públicas: no incluyas tokens, credenciales ni datos privados. Esta política se actualizará si cambia el tratamiento de datos del programa.
